## 1. Minecraft 是什么

《Minecraft（我的世界）》本质上是一款 **开放世界 + 沙盒 + 生存 + 建造 + 探索 + 自动化** 的游戏。
它不像传统 RPG 那样要求玩家沿固定主线前进，而是先给玩家一个由大量方块和规则组成的世界，然后允许玩家自己决定目标。

你可以：生存、挖矿、盖房子、探索地图、战斗、打 Boss、研究红石、建自动化工厂、玩多人服务器、装 MOD，甚至在游戏里造一台计算机。

### 1.1 核心循环

```
出生 → 获取资源 → 制造工具 → 提高资源获取效率 → 探索更危险区域
    → 获得高级资源 → 升级装备 → 自动化生产 → 扩大基地
    → 探索更多区域 → 挑战 Boss → 进入后期自由发展
```

### 1.2 它同时是哪几种游戏

Minecraft 之所以能玩几千小时，是因为它不止一条玩法。它可以同时被理解为：

| 视角 | 你在做什么 |
| --- | --- |
| 生存游戏 | 找食物、防怪物、管理生命与饥饿 |
| 建筑游戏 | 从木屋到城市，没有终点 |
| 探索游戏 | 生物群系、地下、结构、三个维度 |
| 战斗游戏 | 怪物、Boss、PVP |
| 自动化 / 工业 / 物流游戏 | 红石、农场、刷怪塔、分类仓库 |
| 资源管理游戏 | 装备耐久、库存、交易经济 |
| 社交 / 服务器游戏 | 联机生存、小游戏、RPG 服 |
| 编程逻辑游戏 | 红石逻辑门、命令方块 |
| 地图编辑器 / 游戏开发平台 | 冒险地图、MOD、数据包 |

## 2. 版本

Minecraft 目前主要分为两个版本：

| | Java Edition | Bedrock Edition |
| --- | --- | --- |
| 平台 | Windows、macOS、Linux | Windows、Xbox、PlayStation、Switch、iPhone、iPad、Android |
| 强项 | MOD、服务器、红石、高级玩法、社区生态 | 跨平台联机、手柄与触屏操作 |
| 差异 | UI、战斗机制（攻击冷却）、红石行为、部分生物与世界生成规则存在不同 | |

两个版本的核心玩法基本一致，本文主体内容对两者都适用。

## 3. 菜单与世界设置

### 3.1 主菜单

Java 版：

```
Minecraft
├─ 单人游戏        进入本地世界
├─ 多人游戏        连接服务器
├─ Minecraft Realms 官方托管的私人服务器
├─ 选项            画面、声音、按键、语言、资源包、辅助功能
└─ 退出游戏
```

Bedrock 版：

```
Play
├─ Worlds     本地世界
├─ Friends    好友联机
└─ Servers    服务器
（另有角色、商城、Marketplace 等入口）
```

### 3.2 单人世界列表

点击「单人游戏」后看到自己的世界列表。每个世界通常显示：**世界名称、游戏模式、创建 / 最后游玩时间、版本信息、世界图标**。

可执行的操作：进入世界、创建新世界、编辑世界、删除世界、备份世界、重新创建世界。

### 3.3 创建新世界

创建世界的本质是**设置这个世界的基本运行规则**。

| 设置项 | 作用 |
| --- | --- |
| 世界名称 | 存档名称 |
| 游戏模式 | 生存、创造、极限等（见第 22 部分） |
| 难度 | 和平、简单、普通、困难 |
| 种子 Seed | 决定地形生成结果（见 3.4） |
| 是否允许作弊 | 决定能否使用部分命令 |
| 世界类型 | 普通世界、超平坦等 |
| 数据包 | Java 版可加载自定义规则 |
| 游戏规则 Gamerule | 死亡掉落、天气、昼夜、生物破坏等（见 24.6） |

### 3.4 种子 Seed

Minecraft 的世界不是完全随机生成，而是根据一个 **Seed（种子）** 生成。
相同游戏版本、相同 Seed、相同生成规则，通常可以生成非常相似的世界。

所以玩家会分享「好种子」，例如出生点就在：村庄旁边、沙漠神殿旁边、樱花林附近、巨大山脉附近、海岛。

## 4. 游戏内界面 HUD

进入世界后，屏幕中央是准星，屏幕下方是状态栏与快捷栏。

```
                       [ + ]  ← 准星
                                          ┌ 可能额外显示：
 ♥♥♥♥♥♥♥♥♥♥  生命值     🍖🍖🍖🍖🍖🍖🍖🍖🍖🍖  饥饿值    │  Boss 血条
 ▣▣▣▣▣▣▣▣▣▣  护甲值     ○○○○○○○○○○  氧气（水下）        │  状态效果图标
 ═══════════ 经验条 · 经验等级                          │  骑乘生物生命值
 [1][2][3][4][5][6][7][8][9]  快捷栏                     └
```

### 4.1 准星与互动逻辑

屏幕中心的「+」是准星。Minecraft 绝大多数互动都围绕准星完成：

| 准星对着 | 操作 | 结果 |
| --- | --- | --- |
| 树 | 左键 | 破坏树木 |
| 地面 | 右键 | 放置方块 |
| 怪物 | 左键 | 攻击 |
| 箱子 | 右键 | 打开箱子 |
| 门 | 右键 | 开门 |

所以 Minecraft 的基础互动逻辑就是：**观察目标 → 把准星指向目标 → 执行动作。**

## 5. 玩家状态系统

### 5.1 生命值

默认玩家拥有 **10 颗心 = 20 点生命值**。生命值归零后玩家死亡。

会减少生命值的情况：怪物攻击、玩家攻击、摔落、火焰、岩浆、爆炸、溺水、窒息、中毒、饥饿、虚空、部分特殊伤害。

### 5.2 护甲值

穿戴护甲后，生命值上方出现护甲图标，护甲可以减少大量伤害。

| 护甲材料（由低到高） | 皮革 → 锁链 → 金 → 铁 → 钻石 → 下界合金 |
| --- | --- |
| **完整一套** | 头盔、胸甲、护腿、靴子 |

### 5.3 饥饿值

生存模式存在饥饿系统，玩家拥有 10 个饥饿图标。

- 跑步、跳跃、战斗、自然回血等行为会消耗饱食度。
- 饥饿值较高时，玩家可以**自然恢复生命**。
- 饥饿严重时**无法疾跑**。
- 部分难度下，完全饥饿甚至会持续掉血。

### 5.4 食物

| 类别 | 常见食物 |
| --- | --- |
| 肉类 | 牛排、猪排、鸡肉、羊肉、鱼 |
| 作物 / 加工品 | 面包、胡萝卜、土豆、南瓜派、甜浆果 |
| 果类 | 苹果 |
| 高级 | 金胡萝卜、金苹果 |

不同食物恢复的饥饿值和**隐藏饱和度**不同。高级玩家通常偏向高饱和度食物（如牛排、猪排、金胡萝卜）。

### 5.5 经验值与经验等级

击杀怪物、挖矿、熔炼、繁殖、交易等行为可以获得经验，经验条满后等级提高。

经验主要用于：**附魔、铁砧操作（改名、合并、修复）**。死亡后通常会损失大量经验。

### 5.6 状态效果

玩家可能获得各种状态效果，来源包括：药水、信标、食物、怪物攻击、环境。

| 增益 | 减益 |
| --- | --- |
| 速度、力量、跳跃提升、夜视、抗火、再生、水下呼吸 | 中毒、虚弱、缓慢 |

## 6. 物品栏与装备

### 6.1 快捷栏 Hotbar

屏幕最下方有 9 个快捷栏槽位，用数字键 1～9 或鼠标滚轮切换。一个常见的排布：

| 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 剑 | 镐 | 斧 | 铲 | 食物 | 火把 | 方块 | 水桶 | 弓 |

### 6.2 背包

Java 版按 **E** 打开背包。

- 27 格主背包 + 9 格快捷栏 = **36 个基础物品槽位**。
- 大多数普通物品一格最多堆叠 **64** 个。
- 部分物品只能堆叠 **16** 个（如末影珍珠、雪球、鸡蛋）。
- 武器、工具、护甲等很多物品**不能堆叠**。

### 6.3 角色装备槽与副手

角色拥有：头盔槽、胸甲槽、护腿槽、靴子槽、**副手槽**。

副手常放：盾牌、火把、食物、不死图腾、箭、地图，或其他物品。

## 8. 第一天怎么玩

玩家第一次进入生存世界通常什么都没有。最经典的开局流程：

```
出生
 → 寻找树 → 砍树 → 原木 → 木板 → 木棍 → 工作台
 → 木镐 → 挖石头 → 石镐、石斧、石剑
 → 找煤 / 烧木炭 → 火把
 → 找食物（动物、苹果、浆果）
 → 制作床（3 羊毛 + 3 木板）
 → 找或挖一个临时住所
```

### 为什么第一天要快

- 一整个游戏日大约 **20 分钟**（白天约 10 分钟，夜晚约 7 分钟，加上黄昏与黎明）。
- 白天相对安全，夜晚和黑暗区域会出现大量敌对生物。

所以新手第一天的**必做清单**：

- [ ] 食物
- [ ] 火把
- [ ] 床
- [ ] 武器（至少石剑）
- [ ] 简单住所（哪怕是挖进山里堵上门）

## 9. 世界结构与生成规则

### 9.1 世界由方块组成

整个 Minecraft 世界可以理解为一个巨大的**三维方块数据库**。每个位置都有 X、Y、Z 坐标：

- **X、Z**：水平位置。
- **Y**：高度。

每个坐标上可能是：空气、石头、泥土、草、水、岩浆、矿物、木头、建筑方块，或其他方块。

### 9.2 区块 Chunk

世界由大量 **区块** 组成，一个区块横向是 **16 × 16** 方块。
玩家移动时，附近区块加载、远处区块卸载——这让 Minecraft 能拥有极其巨大的世界。

### 9.3 生物群系 Biome

不同生态区域拥有不同的地形、颜色、植物、动物、天气表现和建筑生成概率。

| 类型 | 例子 |
| --- | --- |
| 温带 | 平原、森林、樱花林 |
| 干旱 | 沙漠、恶地 |
| 寒冷 | 雪原、针叶林 |
| 湿润 | 丛林、沼泽 |
| 高地 | 山地 |
| 水域 | 海洋 |

### 9.4 地下世界

地下不仅有普通矿洞，还可能存在：大型洞穴、废弃矿井、钟乳石洞穴、繁茂洞穴、地下湖、**深暗之域**与**远古城市**。矿洞本身就是一个非常大的探索系统。

### 9.5 自然生成结构

| 维度 | 结构 | 特点 |
| --- | --- | --- |
| 主世界·地表 | 村庄 | 村民、交易、床、据点 |
| | 沙漠神殿、丛林神庙 | 陷阱与战利品 |
| | 掠夺者前哨站、林地府邸 | 高强度战斗 |
| | 沉船、海底遗迹、海底神殿 | 水下探索 |
| 主世界·地下 | 废弃矿井、地牢 | 刷怪笼、箱子 |
| | 要塞 | **末地传送门**所在 |
| | 远古城市 | 深暗之域，极危险 |
| 下界 | 下界要塞 | 烈焰人、凋灵骷髅 |
| | 堡垒遗迹 | 猪灵、高级战利品 |
| 末地 | 末地城 | 潜影贝、鞘翅 |

## 10. 方块、工具与制造

### 10.1 破坏与放置

玩家可以破坏绝大多数方块，也可以把物品栏中的方块重新放回世界。破坏 + 放置 = Minecraft 建筑系统的核心。

用对工具可以大幅提高效率：

| 方块 | 合适工具 |
| --- | --- |
| 泥土、沙、雪 | 铲 |
| 木头 | 斧 |
| 石头、矿石 | 镐 |
| 羊毛、树叶 | 剪刀 |

### 10.2 工具类型

| 工具 | 用途 |
| --- | --- |
| 镐 | 挖石头和矿物 |
| 斧 | 砍木头 |
| 铲 | 挖土、沙、雪 |
| 锄 | 制作耕地 |
| 剑 | 战斗 |
| 剪刀 | 剪羊毛、树叶 |
| 钓鱼竿 | 钓鱼与部分特殊操作 |

### 10.3 工具等级

```
木 → 石 → 铁 → 钻石 → 下界合金
```

黄金比较特殊：挖掘速度快、附魔性好，但耐久很低，一般不作为主力工具。

### 10.4 耐久度

工具、武器、护甲都有耐久度，每次使用可能减少。耐久归零后物品**损坏消失**。所以装备管理也是生存的重要组成部分（后期靠「经验修补」解决，见 15.2）。

### 10.5 工作台与合成

- 玩家自带 **2×2** 合成区域，工作台提供 **3×3** 合成区域。
- 大量重要物品必须在工作台上制作：工具、武器、箱子、熔炉、门、床、盾牌、红石设备。
- 合成需要把材料按配方排列，例如镐：

```
[材料][材料][材料]
[    ][木棍][    ]
[    ][木棍][    ]
```

现代 Minecraft 提供**配方书**，不必背诵所有配方。

### 10.6 熔炉

基本结构：**原料 + 燃料 → 烧制 → 成品**。

| 原料 | 成品 |
| --- | --- |
| 粗铁 | 铁锭 |
| 生牛肉 | 牛排 |
| 沙子 | 玻璃 |
| 原木 | 木炭 |

三种熔炉：

| 熔炉 | 用途 |
| --- | --- |
| 普通熔炉 | 通用 |
| 高炉 | 更快处理矿物和金属 |
| 烟熏炉 | 更快处理食物 |

常见燃料：煤炭、木炭、木板、木头、**岩浆桶**（烧制数量最多）、其他可燃物。不同燃料可烧制的数量不同。

## 11. 矿物与材料等级

### 11.1 常见矿物

煤、铁、铜、金、红石、青金石、钻石、绿宝石。不同矿物在不同高度和地形中的生成概率不同（钻石在低 Y 值更多）。

### 11.2 铁：前中期的基础工业资源

铁可以制造：铁镐、铁剑、护甲、盾牌、桶、剪刀、铁轨、漏斗、铁砧，以及大量红石机械。
所以铁实际上是 Minecraft 的**基础工业资源**，后期靠刷铁机（20.4）实现自动供应。

### 11.3 钻石：进入中期的标志

钻石用于高级装备：钻石镐 / 剑 / 斧 / 铲 / 锄、钻石护甲、附魔台。钻石镐也是高效采集**黑曜石**（下界传送门材料）的必要条件。

### 11.4 下界合金：后期材料

需要先拥有钻石装备，再用下界资源（远古残骸 → 下界合金锭）通过锻造台升级。特点：更高耐久、更好属性、**掉进岩浆不会烧毁**。

## 12. 生存机制：光照、昼夜、床与死亡

### 12.1 火把与光照

火把不仅是照明，也是**防御设施**：敌对生物需要满足特定黑暗条件才能自然生成，给基地和周围照明可以直接降低怪物生成。

常见光源：火把、灯笼、萤石、海晶灯、红石灯、其他发光方块。

### 12.2 昼夜循环

- 白天：探索、采集、建设。
- 夜晚：危险增加。
- 睡床可以跳过大部分夜晚。

### 12.3 床

床有两个作用：**跳过夜晚**、**设置重生点**。
睡过床后，死亡会在该床附近重生；如果床被破坏或被阻挡，会回到世界出生点。

### 12.4 死亡

普通生存模式下：

1. 装备和背包物品**掉落在死亡地点**。
2. 玩家在重生点重新出现。
3. 掉落物在区域持续加载的情况下，约 5 分钟后消失。

所以死亡后通常要**快速返回死亡地点捡装备**。

### 12.5 keepInventory

通过游戏规则可以修改死亡行为。`keepInventory` 开启后，死亡时**保留背包物品和装备**——常见的新手或休闲服务器设置。

## 13. 农业与畜牧

### 13.1 农田

基本逻辑：

```
水源 → 用锄制作耕地 → 播种 → 等待成长 → 收获 → 重新播种
```

常见作物：小麦、胡萝卜、土豆、甜菜、南瓜、西瓜、甘蔗、竹子。

### 13.2 动物

常见被动动物：牛、猪、羊、鸡、兔、马、狼、猫、蜜蜂、鱼类。它们提供食物、材料、交通或其他功能。

### 13.3 繁殖

| 动物 | 繁殖食物 |
| --- | --- |
| 牛、羊 | 小麦 |
| 猪 | 胡萝卜、土豆、甜菜根 |
| 鸡 | 种子 |

用两份食物喂两只动物即可繁殖，由此建立畜牧场。

## 14. 生物与战斗

### 14.1 敌对生物

| 生物 | 特点 | 应对 |
| --- | --- | --- |
| 僵尸 | 近战、主动追踪；白天在阳光下燃烧 | 正面打，盾牌好用 |
| 骷髅 | 弓箭远程，对新手威胁高 | **盾牌**挡箭，贴身打 |
| 苦力怕 | 靠近后「嘶」声倒计时爆炸，会炸坏建筑 | 打一下就后退，或用弓远程 |
| 蜘蛛 | 速度快、能爬墙；白天可能中立 | 站高处，不要在开阔地夜战 |
| 末影人 | 瞬移；直视眼睛会激怒它；掉末影珍珠 | 不看它的头，或戴南瓜头 |
| 女巫 | 扔药水 | 远程或速战 |
| 史莱姆 | 分裂 | 沼泽 / 特定区块出现 |
| 幻翼 | 长时间不睡觉后夜间出现 | 睡觉 |
| 溺尸 | 水下僵尸，可能扔三叉戟 | 避免夜间下水 |
| 掠夺者 | 弩，成群 | 前哨站附近小心 |
| 其他维度生物 | 见 17.2 | |

### 14.2 战斗基础

Minecraft 战斗包括：近战、远程、盾牌防御、药水、附魔、地形利用。

**Java 版近战有攻击冷却**：等攻击恢复后再攻击，伤害更高。乱点鼠标反而打不出伤害。

### 14.3 武器

| 武器 | 说明 |
| --- | --- |
| 剑 | 基础近战 |
| 斧 | 伤害高、攻速慢，可打破盾牌 |
| **盾牌** | 减少或阻挡正面伤害，尤其适合骷髅箭、僵尸、部分爆炸；**拿到铁后就做** |
| 弓 | 经典远程，常见附魔：力量、冲击、火矢、无限、耐久 |
| 弩 | 装填后可保持待发，附魔与弹药机制不同于弓 |
| 三叉戟 | 可近战可投掷，特定附魔可实现雨天飞行（激流）与召雷（引雷） |

### 14.4 末影珍珠

可投掷，玩家瞬移到落点附近并受少量伤害。也是制造**末影之眼**的关键材料（见 17.3）。

## 15. 附魔、铁砧与药水

### 15.1 附魔系统

附魔可以强化装备。基础需求：**附魔台 + 经验等级 + 青金石**。附魔台周围放**书架**（最多 15 个）可以提高可提供的附魔等级。

### 15.2 常见重要附魔

| 附魔 | 效果 | 用在 |
| --- | --- | --- |
| 效率 | 提高挖掘速度 | 镐、斧、铲 |
| 耐久 | 降低耐久消耗 | 所有装备 |
| **经验修补** | 获得经验球时优先修复装备 | 所有装备，**后期最重要** |
| 时运 | 增加部分矿物掉落量（时运 III 一个钻石矿可掉多个钻石） | 镐 |
| 精准采集 | 直接获得方块本体（如矿石方块、玻璃、冰） | 镐 |
| 保护 | 降低受到的伤害 | 护甲 |
| 锋利 | 提高近战伤害 | 剑、斧 |
| 力量 | 提升弓箭伤害 | 弓 |
| 无限 | 普通箭几乎不消耗 | 弓 |

> 时运与精准采集互斥，所以高级玩家通常准备两把镐：**时运镐**（挖矿）和**精准采集镐**（收集方块）。
>
> **经验修补 + 耐久 III** 组合后，高级装备几乎可以永久使用。

### 15.3 铁砧

铁砧可以：修复装备、合并附魔、修改物品名称、把附魔书应用到装备。使用铁砧需要消耗经验等级。

### 15.4 药水

进入下界并获得烈焰棒（做酿造台）后，可以建立酿造系统：

```
水瓶 → + 下界疣 → 粗制药水 → + 材料 → 特殊药水 → （+ 红石延时 / + 萤石增强）
```

常见药水：力量、迅捷、抗火、夜视、隐身、水下呼吸、治疗、再生、缓降。

**抗火药水**在下界尤其重要：一定时间内大幅降低火焰和岩浆威胁。

## 16. 村庄与村民经济

### 16.1 村庄

世界会自然生成村庄，包含：村民、房屋、床、工作站、农田、铁傀儡。村庄可以成为非常重要的生存据点。

### 16.2 村民职业

村民通过附近的**工作站方块**获得职业：

| 工作站 | 职业 | 主要交易 |
| --- | --- | --- |
| 讲台 | **图书管理员** | 附魔书 |
| 堆肥桶 | 农民 | 作物 ↔ 绿宝石、食物 |
| 制箭台 | 制箭师 | 箭、弓 |
| 锻造台 | 工具匠 | 工具 |
| 砂轮 | 武器匠 | 武器 |
| 高炉 | 盔甲匠 | 护甲 |

### 16.3 村民交易

村民使用**绿宝石**作为主要货币。玩家可以：出售农作物换绿宝石 → 购买工具、装备、附魔书、食物和其他资源。后期村民交易可以形成完整经济体系。

### 16.4 图书管理员为什么最重要

它可以提供附魔书。高级玩家通过村民体系稳定获得：**经验修补、耐久 III、效率 V、保护 IV、锋利 V** 等高级附魔，绕开附魔台的随机性。

### 16.5 铁傀儡

铁傀儡保护村庄和村民，攻击部分敌对生物。玩家如果误伤村民或铁傀儡，可能遭到反击。铁傀儡的生成机制也是刷铁机的基础（20.4）。

## 17. 三大维度与主线推进

Minecraft 核心世界由三个维度组成，它们共同构成最经典的成长路线：

```
主世界 Overworld ──(黑曜石传送门)──▶ 下界 Nether ──(烈焰棒)──┐
        ▲                                                   │
        └───────(要塞·末地传送门·末影之眼)◀────────────────────┘
                              │
                              ▼
                         末地 The End ──▶ 末影龙 ──▶ 末地外岛 ──▶ 末地城 ──▶ 鞘翅
```

### 17.1 主世界 Overworld

玩家默认出生的维度：森林、平原、沙漠、海洋、山脉、洞穴、村庄、地下城市和各种自然结构。绝大多数玩家的主基地在主世界。

### 17.2 下界 Nether

**进入方式**：用黑曜石搭建传送门框架（最小 4×5），用打火石点燃。黑曜石需要钻石镐才能高效采集。

**环境特点**：大量岩浆、没有正常昼夜、下界森林、灵魂沙谷、玄武岩三角洲、大量危险生物，**水会瞬间蒸发**。

**下界生物**：

| 生物 | 特点 |
| --- | --- |
| 猪灵 | 穿金护甲则中立，可用金锭「以物易物」 |
| 猪灵蛮兵 | 堡垒遗迹守卫，极强 |
| 恶魂 | 飞行，发射火球（可打回去） |
| **烈焰人** | 下界要塞出现，掉**烈焰棒** |
| 凋灵骷髅 | 下界要塞出现，掉凋灵骷髅头（召唤凋灵） |
| 岩浆怪 | 下界版史莱姆 |
| 疣猪兽 | 下界食物来源 |
| 僵尸猪灵 | 中立，打一只全群攻击 |

**下界要塞**：最重要的下界结构。烈焰人掉落的**烈焰棒**是主线推进的关键：

```
烈焰棒 → 烈焰粉 ──┐
                  ├──▶ 末影之眼 → 寻找要塞 + 激活末地传送门
末影珍珠 ─────────┘
烈焰棒 → 酿造台 → 药水系统
```

**空间比例**：下界横向移动 1 格 ≈ 主世界横向移动 **8 格**。因此高级玩家在下界建立远距离交通网络：下界铁路、冰船高速公路、传送门枢纽。

### 17.3 末影之眼与要塞 Stronghold

1. 投掷末影之眼，它会朝最近的要塞方向飞行（有概率碎掉）。
2. 重复「投掷 → 移动」直到眼睛向下落，在此处向下挖。
3. 要塞是大型地下结构，内含**末地传送门房间**。
4. 把末影之眼填满传送门框架（12 格）激活，跳入进入末地。

### 17.4 末地 The End

**特点**：大量末地石、大量末影人、中央岛屿、**末影龙**。击败末影龙是 Minecraft 最经典的主线目标。

**末影龙战斗流程**：

```
进入末地 → 摧毁黑曜石柱顶端的末地水晶（它们为龙回血）
        → 攻击末影龙（弓射空中，龙降落在传送门时近战）
        → 击杀
```

**击败之后**：掉落大量经验、打开返回主世界的传送门、出现**末地折跃门**（扔末影珍珠进入）→ 探索末地外岛。所以 Minecraft 不会因为末影龙死亡而真正结束。

**末地城**：外岛可能生成末地城，包含潜影贝、高级战利品、末地船，以及船上的**鞘翅**。

## 18. 后期装备与储物

### 18.1 鞘翅

后期极其重要的移动装备，装备在**胸甲位置**可以滑翔，配合**烟花火箭**可以持续飞行。玩家交通从此变为：

```
步行 → 船 → 马 → 矿车 → 鞘翅飞行
```

### 18.2 潜影盒

击杀潜影贝获得潜影壳 → 制造潜影盒。核心特点：**盒子内有物品时挖掉盒子，物品仍然保留在盒子里**。相当于移动储物箱，一个潜影盒 = 27 格。

### 18.3 末影箱

末影箱拥有**独立的个人库存**：无论在哪个末影箱打开，看到的都是自己的同一套物品。类似跨地点同步的私人储物空间。

后期经典组合：**末影箱 + 潜影盒 + 鞘翅** —— 末影箱里放潜影盒，随身携带上千格物资，飞到哪用到哪。

## 19. Boss 与信标

### 19.1 凋灵 Wither

Minecraft 经典 Boss，由玩家**主动召唤**：

```
   [头][头][头]
   [沙][沙][沙]     沙 = 灵魂沙或灵魂土
       [沙]         头 = 凋灵骷髅头（下界要塞获取）
```

凋灵非常危险（飞行、爆炸、凋零效果）。击败后掉落**下界之星**。

### 19.2 信标 Beacon

下界之星 → 信标。把信标放在由铁 / 金 / 钻石 / 绿宝石 / 下界合金块构成的金字塔上，可给附近玩家提供强化效果：

| 效果 | 用途 |
| --- | --- |
| 速度 | 移动 |
| **急迫** | 提升挖掘速度 |
| 力量 | 战斗 |
| 跳跃提升 | 移动 |
| 抗性提升 | 减伤 |
| 生命恢复 | 回血 |

### 19.3 急迫 + 效率 V

高级玩家常用组合：**效率 V 镐 + 急迫 II**，可以瞬间挖掉石头，进行超高速挖掘和大型工程建设。

## 20. 红石与自动化

### 20.1 红石是什么

红石可以理解为 Minecraft 内置的「电路系统」。它允许玩家制造：开关、逻辑门、自动门、机关、农场、运输系统、自动仓库、复杂机器，甚至计算机。

### 20.2 红石元件

| 元件 | 作用 | 类比 |
| --- | --- | --- |
| 红石粉 | 传递信号（最远 15 格） | 导线 |
| 按钮、拉杆、压力板、红石火把、侦测器、目标方块 | 产生信号 | 电源 / 开关 |
| 中继器 | 延长信号、控制方向、加入延迟 | 放大器 / 延时器 |
| 比较器 | 读取容器物品数量、比较信号强弱 | 传感器 / 比较电路 |
| 活塞 / 粘性活塞 | 推动 / 推拉方块 | 执行器 |
| 观察者 | 检测相邻方块变化并发出脉冲（植物成长、方块变化、活塞运动） | 变化检测器 |
| 漏斗 | 吸取、运输物品，送进箱子 / 熔炉 | 传送带 |

活塞可以做出：隐藏门、升降机、机械结构、自动农场、大型机器。
漏斗是**自动化物流的核心**。

### 20.3 自动化：从「自己挖」到「机器产」

| 前期 | 后期 |
| --- | --- |
| 玩家亲自采集资源 | 玩家制造机器自动生产资源 |

常见自动化设施：

| 类别 | 设施 |
| --- | --- |
| 作物 | 自动小麦农场、甘蔗机、竹子机、南瓜机、西瓜机 |
| 生物 | 刷铁机、刷怪塔、经验农场、火药农场、金农场 |
| 加工 | 自动熔炉、自动仓库 |

### 20.4 刷铁机

利用村庄与铁傀儡生成机制持续获得铁。建成后，玩家从「到处挖铁」转变为「自动获得大量铁」——这是 Minecraft **工业化的标志**。

### 20.5 刷怪塔

利用敌对生物生成规则：

```
创造黑暗生成平台 → 让怪物集中 → 水流运输 → 击杀（摔落 / 玩家） → 收集掉落物
```

可获得：火药、骨头、线、腐肉、经验及其他资源。

### 20.6 仓储系统的演进

```
箱子 → 大型仓库 → 漏斗系统 → 自动分类仓库
```

自动分类仓库：玩家放入混合物品后，漏斗 + 比较器的过滤电路把每类物品送入对应箱子。

## 21. 建筑

### 21.1 没有终点的系统

玩家可以建造：木屋、现代住宅、城堡、城市、摩天大楼、机场、地铁、工业区、工厂、港口、巨型雕塑、现实建筑复刻，甚至完整国家。

### 21.2 高级建筑思维

高级建筑不只是堆方块，还会考虑：

| 维度 | 关注点 |
| --- | --- |

## 22. 游戏模式、难度与天气

### 22.1 游戏模式

| 模式 | 特点 | 适合 |
| --- | --- | --- |
| **生存** | 资源有限、需要采集与制造、有生命与饥饿、怪物攻击、死亡掉落 | 最经典玩法 |
| **创造** | 无限资源、可飞行、瞬间破坏、无伤害、不需要食物 | 建筑设计、红石测试、地图制作、实验 |
| **极限 Hardcore** | Java 版固定困难难度，**一条命**，死亡后不能正常继续 | 100 天 / 1000 天 / 10000 天挑战 |
| **冒险** | 不能随意破坏方块，地图作者控制可破坏 / 可放置的方块 | 剧情地图、RPG 地图 |
| **旁观** | 像幽灵：可飞、穿墙、不与世界互动 | 观察地图、管理员巡查、看地下结构、观战 |

### 22.2 难度

| 难度 | 说明 |
| --- | --- |
| 和平 | 基本不出现敌对怪物，饥饿不掉血 |
| 简单 | 伤害较低 |
| 普通 | 标准体验 |
| 困难 | 危险明显提高，影响部分生物行为（僵尸破门、饥饿可致死） |

### 22.3 天气

晴天、下雨、雷暴。天气不仅影响视觉，也影响机制（下雨可钓鱼加速、雷暴时白天也可能刷怪）。

**雷暴与闪电**：苦力怕被雷击变成**高压苦力怕**；村民被雷击变女巫、猪变僵尸猪灵等特殊转化。

## 23. 多人游戏

### 23.1 玩法类型

朋友联机生存、私人服务器、大型公共服务器、小游戏服务器、RPG 服务器、经济服务器、战争服务器、建筑服务器、无政府服务器。

### 23.2 服务器规则

服务器可以在原版基础上增加：货币、商店、拍卖、领地、公会、职业、任务、传送、排行榜、PVP、副本、经济系统。因此不同服务器实际上可能像**完全不同的游戏**。

### 23.3 Realms

Minecraft 官方提供的私人服务器服务。适合朋友联机、家庭联机、小型长期世界。优点是配置简单，不需要自己维护服务器环境。

### 23.4 PVP

玩家对玩家战斗：剑战、水晶 PVP、弓战、盾牌战、团队战、资源争夺。不同服务器可能修改 PVP 规则。

## 24. 扩展与定制：资源包、光影、MOD、命令

### 24.1 资源包

改变方块纹理、物品纹理、声音、字体、部分模型、UI 表现。同一个世界可以呈现完全不同的视觉风格。

### 24.2 光影 Shader

真实阴影、动态阳光、水面反射、体积云、体积雾、环境光、发光效果。高质量光影可以让画面风格发生巨大变化（需要较强显卡）。

### 24.3 MOD

Java 版拥有非常庞大的 MOD 生态，可以加入：新方块、新工具、新机器、新生物、新 Boss、新维度、魔法、工业、科技、自动化、UI、任务、完整剧情。

| 类型 | 玩法变化 |
| --- | --- |
| **科技 MOD** | 采矿 → 发电 → 机器 → 矿物处理 → 自动化 → 电网 → 大型工厂；最终可能出现核电、自动流水线、数字存储、复杂物流 |
| **魔法 MOD** | 法术、魔法装备、魔力系统、祭坛、新 Boss、新维度、魔法自动化 |

因此 Minecraft 实际上是一个非常强大的**游戏底座**。

### 24.4 命令

| 命令 | 作用 |
| --- | --- |
| `/tp` | 传送 |
| `/give` | 给予物品 |
| `/gamemode` | 改变游戏模式 |
| `/summon` | 生成实体 |
| `/setblock` | 设置方块 |
| `/fill` | 批量修改方块 |
| `/time` | 修改时间 |
| `/weather` | 修改天气 |

需要世界开启「允许作弊」或服务器管理员权限。

### 24.5 命令方块

命令方块可以自动执行命令，地图作者用它制造：剧情触发器、传送系统、任务、Boss、机关、对话、奖励系统、小游戏、复杂地图逻辑。它很像 Minecraft 内部的**脚本系统**。

### 24.6 游戏规则 Gamerule

| 规则 | 作用 |
| --- | --- |
| `keepInventory` | 死亡是否保留物品 |
| `doDaylightCycle` | 昼夜是否变化 |
| `doWeatherCycle` | 天气是否变化 |
| `mobGriefing` | 生物是否可以破坏环境（苦力怕炸地形、末影人搬方块） |

用法：`/gamerule keepInventory true`。这些规则让服务器和地图可以高度定制。

## 25. 成长路线与发展阶段

### 25.1 Minecraft 真正的「主线」

没有强制主线，但存在非常明显的自然成长路线：

```
出生 → 砍树 → 工作台 → 石器 → 铁器 → 钻石 → 附魔 → 黑曜石
  → 下界 → 下界要塞 → 烈焰棒 → 末影珍珠 → 末影之眼 → 要塞
  → 末地 → 末影龙 → 末地外岛 → 末地城 → 鞘翅 → 后期自由发展
```

### 25.2 后期怎么玩

击杀末影龙不代表结束。后期玩家通常会：建大型基地、自动农场、刷怪塔、自动仓库、村民交易大厅；收集全部装备、鞘翅、潜影盒；建立下界交通；制作信标；挑战凋灵；建城市；完成大型红石项目；探索更多世界。

### 25.3 玩家关心的问题如何变化

| 阶段 | 核心问题 |
| --- | --- |
| 前期 | 我怎么活下去？ |
| 中期 | 我怎么获得更好的装备？ |
| 中后期 | 我怎么更快获得资源？ |
| 后期 | 我怎么让机器帮我生产资源？ |
| 终局 | 我想用这些资源创造什么？ |

这也是 Minecraft 最核心的设计魅力。

## 26. 底层规则与系统视角

### 26.1 八条核心规则

把整个 Minecraft 压缩到最基础，可以归纳为八条：

1. 世界由可以互动的**方块和实体**组成。
2. 玩家可以**破坏和重新放置**大量方块。
3. 资源需要通过**探索、采集、交易或生产**获得。
4. 不同**工具和装备**决定资源获取和战斗效率。
5. 世界按照固定的**物理、生物、光照、生成和时间规则**运行。
6. 玩家可以利用规则建立**自动化系统**。
7. 世界几乎**没有固定终点**。
8. 玩家**自己决定最终目标**。

### 26.2 把 Minecraft 看成一个系统

```
输入                处理过程              输出
────────            ────────              ────────
玩家操作            探索                  资源
世界资源            采集                  装备
时间        ──▶     合成         ──▶      建筑
生物                战斗                  机器
环境                建造                  交通网络
规则                交易                  城市
                    自动化                整个玩家创造出来的世界
```

### 26.3 最终理解

Minecraft 表面上是一款方块游戏，但它真正的核心不是「挖矿」或「盖房子」，而是给玩家一个**有稳定规则的数字世界**，让玩家利用规则不断提高自己的能力。

从徒手砍树，到拥有工具，再到工业化资源、自动农场、交通网络、城市和大型工程，整个过程就是：

```
生存 → 发展 → 工业化 → 自动化 → 创造
```

因此 Minecraft 最核心的玩法不是「完成任务」，而是：

> **利用世界规则，把一个最初与你无关的随机世界，逐渐改造成属于你自己的系统。**

## 附录 B：新手常见问题

**Q：第一晚来不及做床怎么办？**
挖进山里或往下挖 3 格，用方块把出入口堵上，等到天亮。

**Q：死了东西在哪？**
在死亡地点附近，约 5 分钟内赶回去。开 `keepInventory` 可以避免掉落。

**Q：为什么打不到伤害？**
Java 版有攻击冷却，等剑图标恢复后再挥。

**Q：末影人为什么追我？**
你看了它的眼睛。移开视线或戴南瓜头。

**Q：铁不够用？**
前期多挖矿洞；中期建刷铁机；后期铁基本无限。

**Q：怎么去下界 / 末地？**
下界：黑曜石传送门 + 打火石。末地：烈焰棒 + 末影珍珠 → 末影之眼 → 找要塞 → 填满传送门。

**Q：打完末影龙还有什么可玩？**
末地城、鞘翅、凋灵、信标、自动化、建筑、服务器、MOD——真正的游戏才刚开始。
