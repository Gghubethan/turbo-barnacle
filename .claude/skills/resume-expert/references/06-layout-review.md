# ⑥ 结构复查

改完内容再看整体。四件事：模块顺序、内容重复、信息密度、总长度。

## 模块顺序

按身份选模板，**最相关的放最前**：

| 身份 | 推荐顺序 |
| --- | --- |
| 应届 / 实习 | 基本信息 → 教育背景 → 实习/项目经历 → 校园经历 → 技能 → 荣誉 |
| 社招 1-5 年 | 基本信息 →（求职意向/一句话摘要）→ 工作经历 → 项目经历 → 技能 → 教育背景 |
| 社招 5 年+ | 基本信息 → 一句话摘要 → 工作经历 → 核心能力/技能 → 教育背景（可压成一行） |
| 转行 | 基本信息 → 摘要（讲清转行逻辑）→ 可迁移能力/相关项目 → 工作经历 → 教育背景 |
| 学术 | 基本信息 → 教育背景 → 研究方向 → 论文/成果 → 项目 → 技能（长度规则另论） |

硬规则：**同一模块内严格时间倒序**（最近的在最上面），无一例外。

## 内容重复

三种典型重复，都要合并：

1. **技能栏 vs 经历**：技能栏写"精通 Python"，经历里又写"使用 Python 完成 X"——保留经历里的事实版本，技能栏只留词表。
2. **摘要 vs 经历**：自我评价把经历复述一遍——摘要只保留"身份 + 年限 + 一句能力锚点"。
3. **跨段重复**：两段经历写同一件事（换了措辞）——保留在更相关/更近的那段，另一段删掉或改成不同侧面。

## 信息密度

| 指标 | 健康区间 | 超标处理 |
| --- | --- | --- |
| 单条 bullet | 25-45 字（中文）/ 1-2 行 | 拆或删 |
| 单段经历 bullet 数 | 3-5 条 | 只留与目标岗位最相关的 |
| 每段经历行数 | 4-7 行 | 压缩 |
| 全篇留白 | 15%-25% | 太满读不动，太空显得没内容 |
| 摘要 | 2-3 行 | 超过就是自我感动 |

**密度不是越高越好。** 塞满两页不如写满一页 —— 阅读成本是简历的第一成本。

## 总长度

- **应届 / 3 年以内**：1 页。超出就是没做取舍。
- **3-10 年**：1-2 页，2 页必须第 2 页有实质内容（不能只有三行溢出）。
- **10 年+ / 学术 / 高管**：2 页+ 可接受，但前 1 页要能独立成立。

超长时的删减顺序：自我评价 → 兴趣爱好 → 与目标无关的早期经历（可合并成一行"更早经历：XX公司 / 职位 / 年份"）→ 技能栏冗余词 → 每段 bullet 砍到 3 条。

## 分页

- 一段经历不能被硬切到两页（公司名在第 1 页底、bullet 在第 2 页顶是最差情况）。
- 模块标题不能出现在页面最后一行（孤行）。
- 第 2 页顶部建议重复姓名（一行即可），防止打印后散页。
- 具体实现（段中不分页 / 与下段同页）见 `08-docx-format.md`。

## 产出

结构复查的结论合并进诊断报告或改写确认里，不单独开一轮对话。典型输出：

```
结构复查：
- 模块顺序：建议把「项目经历」提到「工作经历」之后、「技能」之前（当前在最末，你最强的证据被埋了）🔴
- 重复：技能栏「熟悉 SQL」与工作经历第 1 段重复，建议技能栏只留词表 🟡
- 长度：当前 2.3 页，第 3 页只有 2 行 —— 压到 2 页整 🔴
- 密度：第 2 段 7 条 bullet，建议留 4 条（已标出建议删除的 3 条）🟡
```
