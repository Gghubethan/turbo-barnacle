# ⑧ 自动排版（DOCX / PDF）

排版规格集中在 `assets/format-profiles.json`，两套 profile：`zh`（中文简历）/ `en`（English resume）。**改排版改那个 JSON，不要改脚本。**

## 两条路线，按用户诉求选

| 场景 | 用 | 行为 |
| --- | --- | --- |
| 已走完改写，要一份干净的新简历（推荐） | `build_docx.py` | 从 `resume.edited.json` **重建**：单栏、无表格布局、无文本框，天然 ATS 友好 |
| 用户想保留自己的版式，只修排版毛病 | `format_docx.py` | **不重建**，在原 DOCX 上规范字体/字号/行距/页边距/对齐/项目符号，内容一字不动 |

两个脚本都**不覆盖输入文件**，输出到新路径。

```bash
S=.claude/skills/resume-expert/scripts
python3 $S/build_docx.py resume-work/resume.edited.json -o "resume-work/张三-数据分析-简历.docx" --pdf
python3 $S/format_docx.py resume-work/原简历.docx -o resume-work/排版修正版.docx --profile zh
python3 $S/format_docx.py resume-work/原简历.docx --dry-run              # 只看会改什么，不写文件
```

## 规格（zh profile 的默认值）

| 项 | 值 | 为什么 |
| --- | --- | --- |
| 页边距 | 上下左右 1.8cm | 小于 1.27cm 打印会切边，大于 2.5cm 浪费版面 |
| 中文字体 | 微软雅黑（备选 思源黑体 / 苹方 / 宋体） | 覆盖率高，屏幕可读性好 |
| 西文/数字 | Calibri | 与雅黑混排不打架；**中英文必须分别设定**，否则数字会被中文字体渲染得很丑 |
| 姓名 | 20pt 加粗 | 一眼定位 |
| 联系方式 | 9.5pt | 信息必要但不抢戏 |
| 模块标题 | 12pt 加粗 + 下划横线 | 扫读锚点 |
| 公司/职位行 | 10.5pt 加粗，时间右对齐同一行 | 一行读完"哪家、什么岗、什么时候" |
| 正文 / bullet | 10.5pt | 低于 10pt 打印吃力，高于 11pt 放不下 |
| 行距 | 1.15 倍 | 1.0 太挤，1.5 太散 |
| 段间距 | 模块前 10pt、条目前 6pt、bullet 后 2pt | 用间距分组，比空行可控 |
| 对齐 | 全部左对齐 | **禁止两端对齐**：会拉出难看的字间空隙，英文尤其明显 |
| 项目符号 | `•` + 悬挂缩进 0.5cm | 用真实的悬挂缩进，不要用空格/Tab 对齐 |
| 分页 | 条目整体不跨页、标题跟随下段 | 避免公司名在页底、内容在页顶 |

## 排版硬规则（脚本已实现，人工改也要守）

1. **单栏**。双栏在 ATS 里会串行。
2. **不用表格做版面**（脚本重建时不产生表格）。真需要"左内容右时间"，用制表位（tab stop）实现，脚本已用右对齐制表位。
3. **不用空行调间距**，用段前段后间距——空行在不同 Word 版本里高度不一样。
4. **不用文本框、艺术字、图片承载文字**。
5. **联系方式放正文首行，不放页眉页脚**。
6. **一份文档只用 1-2 种字体**，靠字号和粗体做层级，不靠颜色。颜色最多一个深色作为标题点缀，且黑白打印要能看。

## 转 PDF

`--pdf` 调用本机 LibreOffice（`soffice`）转换。没装就只出 DOCX，并提示用户在 Word 里「另存为 PDF」（**不要**用"打印成图片"）。转完必须确认：PDF 里文字可以选中复制（`ats_check.py` 会再验一次）。

## 排版后必看

- [ ] 实际页数符合 `06-layout-review.md` 的长度规则
- [ ] 没有一段经历被切到两页
- [ ] 中文和数字/英文的字体分别正确（放大看数字是不是雅黑渲染的）
- [ ] 项目符号对齐一致，第二行文字与第一行文字左边缘对齐（悬挂缩进生效）
- [ ] 链接是纯文本或可点击，不是被 Word 截断的长 URL
- [ ] 对产物重跑一次 `ats_check.py`，确认原问题清零
