# 宝岛专业服务流程（一页版）

```
进店 ─▶ 注册/查会员 ─▶ 需求互动 ─▶ 黑科技四设备（眼轴 / AI眼底 / 视功能筛查 / …）
     ─▶ 验光室（基础 + 视功能：1+3 / 1+7 / 1+10，最长约 1 小时）
     ─▶ 互动屏解读报告 + 解决方案（无价格、先原理）─▶ 品牌系列 → 折射率/膜层 → 折扣
     ─▶ 选框（A 与 B 搭配约束）─▶ 成交 ─▶ 取镜/售后权益 ─▶ 加企微 ─▶ 复查提醒 / 生命周期回访 ─▶ 回店
```

- 顾客想先看框：两条动线之一（见 [[门店动线与A类陈列]]），但解决方案讲解不能跳过。
- 与普通店的差异点：设备、装修、视功能检查、解读画面、道具体验、售后运营。这些是「专业」被感知的地方，避免比价。
- 部门（MOC）职责：找每个环节的感知点，做画面、道具、话术、陈列建议，把后台（专业 / 商品 / 设计）加工到前台。
