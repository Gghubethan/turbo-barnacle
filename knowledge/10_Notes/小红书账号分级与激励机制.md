# 小红书账号分级与激励机制

## 账号分级

- S / A / B 级；S+A 控制在前 30%（相对排名，非绝对标准 → 领导指出「永远上不去」的问题，后续标准会调）。
- 升级看两点：活跃度（发文频次，一两周不发权重下降）、笔记数据质量。

## 激励结构（赏金任务制）

| 阶段 | 内容 |
| --- | --- |
| 上半年 | 全员启动，每周 1 篇 / 每月 4–8 篇任务量 |
| Q3 | 供应商激励项目，人人可参加 |
| Q4 | 资源集中 S/A；高单价项目（厦门新品测评 500 元/篇，地区得 150，60 天；蔡司 20 天项目，金额待核）只给 A/S；B 级持续破壁升级 |
| 明年 | 基础任务（约 100 元）不再给 B 级；B 级有额外预算带动积极性 |

- 供应商常规单价 125 元/天（100 给员工，25 留总部）。

## 领导要求

- 做成游戏化积分：赏金任务 + 常规激励（爆文奖励、流动红旗、持续发文奖励），积分直接换奖金。
- 测算总预算 = 系统费用 + 常规激励 + 赏金任务；给地区一个清晰的人员激励框架。
- 数据只能走接口获取（不能截图），系统费用要 cover。
- 激励方案合并到志阳 / 蒂文那边的总体人员激励里提报。

## 四川痛点

- 内容不知道发什么、发了没人看 → 培训流量机制（竖图 > 横图等）+ 提升内容质量。
