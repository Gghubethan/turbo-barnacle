# 门店动线与 A 类（镜框）陈列

## 原则

- 进店每一步提前设计：不同人群只看到他想看的，一路越看越好、能升单价。
- 进门第一桌 = 获客窗口（橱窗），决定第一印象。
- 陈列**按风格 / 人群成系列**摆；乱放时消费者不会因一只框理解款式。
- 高端品牌进店就要系列全面；常规门店 499 / 699 / 799 / 999 核心价位一定按风格人群摆明白。
- 陈列元素要少（银系列有皮革、丝绸、陶瓷太多），突出商品。
- 陈列跟着主推 / 季节 / 动线经常调整（类比名创优品）。

## 样板店两条动线（写字楼白领店）

| 动线 | 入口 | 顺序 |
| --- | --- | --- |
| 先选框 | 时尚品牌 | YSL 圣罗兰 → Gucci → 贸易金（转写）→ Boss → 万宝龙 → 百德比 / 老阿雷诺（转写）→ 潮牌（哈迪、惠美寿） |
| 先验光 | 验光室出口 | 夏蒙 UT / 高端 / 现代商务 → 同理心（高度数专用）→ One One → 户外品牌 |

## 款式风格标签（BI）

- 十种款式风格标签已打到 A 类库存分析表（自营 5 核心品牌近三年），门店可看自己缺什么风格、按客群配比。
- 新增第 11 风格「北欧极简」（自营 999 系列，β钛，偏男性）；无边框 799 纯钛系列加入无边框风格。
- 供应商品牌（贝拉罗、链子熊等）陆续打标。
