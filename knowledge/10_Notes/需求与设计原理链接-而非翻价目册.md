# 需求与设计原理链接，而不是翻价目册

**原则**：验光之后，一定不能「检查完直接推某个品牌系列」。要把顾客的**需求**（验光单 + 主诉）
和镜片的**设计原理**链接起来，再落到具体商品。

## 为什么

- 翻价目册第一眼是价格 → 顾客心慌、死守预算、后面什么都不听。
- 直接推品牌页 = 和别家同质化竞争；顾客戴了一年不知道自己买了什么。
- 主推产品的设计原理说不清，员工行为就不会改，还是翻价目册。

## 怎么做

1. 互动屏逐项解读报告，画面**不出现价格**。
2. 讲「这类镜片解决什么问题、和普通镜片差在哪」（实拍对比图、供应商道具）。
3. 再点到品牌系列 → 折射率 / 膜层 → 门店折扣 → A + B 合计。
4. 关键词要精准：**自由曲面**为什么好、**优化点**其实是研磨方式。物料清晰了话术才精准。

## 对标签体系的要求

- 标签必须能回答「解决了什么问题」，而不是复制厂商卖点。
- 每个主推系列要有一页能讲清设计原理的素材（自营短期赋能不能因新品停摆）。
