# 功能型单光分级标准（现状与待定）

## 现状

- 现有分档沿用商品部之前的版本；新上的单光品牌几乎都加了**周边视野优化**，按设计原理和卖点应拉进功能型单光。
- 按现标准，SAP 锐界单光应放在**功能型单光 基础版**，与爱赞「背手」（转写，待核）同级。
- 分级 ≠ 价格：锐界（双面自由曲面）分级高于豪雅新明锐 N3（单面），线上新明锐反而贵 100。

## 两个样本

| | SAP 锐界单光 | 豪雅新明锐 N3 |
| --- | --- | --- |
| 设计 | 双面自由曲面（厂商写「双面自由非球面」）| 单面自由曲面 |
| 优化点 | 5000+ | 待补 |
| 渠道 / 价 | 线下 1399，约 7 折，线上未上 | 线上团单 5 折；1.60 约 1400、1.67 约 1999（待核） |
| 分级 | 更高 | 更低 |
| 主推建议 | 1400 价位带线下主推（标星） | — |

## 待定（小象来对接）

1. 基础版的准入：有周边视野优化就算？还是要自由曲面？
2. 分档维度：单面 / 双面自由曲面、优化点数、折射率范围？
3. 分档与「主推 / 标星」的关系：分档是产品属性，主推是地区运营属性，两者分开维护。
4. 毛利数据：锐界 vs 新明锐 折后毛利（领导已要求发出）。

## 决策原则（领导）

- 相同价位带必须有主次；用**标星**，不要「进阶 / 高阶」。
- 主推产品的**设计原理**必须能说清楚（什么叫自由曲面、优化点 = 研磨方式），否则员工不会改行为。
