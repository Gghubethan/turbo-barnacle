# 镜片功能标准化与自动推荐（B 类主线任务）

> 一句话：把各品牌镜片的「功能」拆成统一的、说人话的标签，打到具体商品上，
> 让门店在验光单出来之后能**自动推荐**最合适的镜片，并用普通话解释「为什么适合我」。

## 1. 为什么要做

- **品牌话术普通人听不懂。** 蔡司、依视路、豪雅各有一套名词；细看会发现功能一样、名字不一样
  （"你讲你是波正面，我讲我是瞳孔感光，懂的人知道就是一个意思"）。
- **国内配镜是价格导向。** 顾客不会为一个听不懂的东西多花 500、1000。所以必须讲清楚
  「这个功能到底解决了什么问题」，再三六九等分开。
- **门店行为惯性。** 门店习惯只讲自己熟的品牌（"我习惯蔡司，依视路我不管"）；
  验完光直接翻价目册推某个品牌系列 = 同质化竞争。目标是**需求 ↔ 设计原理**链接，
  而不是**度数 → 品牌页**。见 [[需求与设计原理链接-而非翻价目册]]。
- **横向对比必须放在同一维度。** 类比宝马 vs 奔驰：技术一样、各叫各的名字，对比时一定要拉到同一维度。

## 2. 目标形态（产品端：iPad / 互动屏）

```
验光报告单 ──▶ 需求识别 ──▶ 标准化功能标签 ──▶ 命中商品集合 ──▶ 自动推荐 + 「为什么适合你」
(度数/散光/视功能/年龄/主诉)   (跨品牌统一)      (所有满足该标签的 SKU 一起出来)
```

- 顾客量完度数后直接知道「这个最适合我」，并且用普通话知道为什么。
- 同一标签下，各品牌满足该需求的商品**一起出来**，避免门店只推熟悉品牌。
- 前提：**先把标签打好**。没有标签，自动推荐无从谈起。

## 4. 已知约束与坑

- **标签要受控**：同一功能只允许一个标签名（避免 `防蓝光`/`蓝光防护`/`抗蓝光` 混用），否则推荐不稳定。
- **各厂商对同一工艺叫法不同**："双面自由曲面"、"双面自由非球面"、"自由双面曲面" 是一回事；
  "优化点"（如锐界单光 5000+ 优化点）本质是**研磨方式**的差异 —— 要拆到工艺层面才能讲清。
- **分级 ≠ 价格**：产品分级里锐界（双面自由曲面）高于豪雅新明锐 N3（单面），但线上新明锐反而贵 100 元。
  推荐逻辑要同时看「分级」「毛利」「主推」，不能只看价格。
- **不要造新的抽象概念**：领导明确不要「进阶/高阶」这类顾客听不懂的分层词，用「主推 / 标星」直接标。
- **品牌方素材不可直接用**：豪雅给的文字版初稿功能卖点重复、说不清，要让他们改；供应商的折射率对比图各画各的，
  互动屏上的画面都是部门自己重做的。

## 5. 待确认问题

1. 「功能型单光 基础版」的准入门槛是什么？周边视野优化算不算？（现状：新上的单光品牌几乎都加了周边视野优化）
2. 标签打在**系列**级还是 **SKU** 级？（折射率/膜层会拆成 SKU，功能应在系列级）
3. 验光单哪些字段能进推荐规则？主诉（看手机多、开车多）如何结构化录入？
4. 自动推荐输出多少个候选？相同价位带如何定主次（毛利 / 主推标星）？
5. 青控推荐：按不同光学原理 + 防控效果数据细分（数据已有，待归类）。
