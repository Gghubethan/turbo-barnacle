# 镜片功能标签体系（草案 v0.1）

> 目的：给「自动推荐」提供一份**跨品牌统一、说人话、受控**的标签词表。
> 机器可读版本见同目录 `lens_taxonomy.yaml`。本稿只收录会议里出现过的信息，
> 空白处标 `待补`，品牌/系列名按转写原文记录、标 `待核`。

## 0. 设计原则

1. **一个功能一个标签**，标签名必须是顾客听得懂的话（"看手机不累" 而不是 "调节支持"）。
2. **三层结构**：`解决什么问题（顾客语言）` → `功能标签（受控词）` → `品牌系列（同义词表）`。
3. 横向对比只在**同一维度**内做；不同维度不比。
4. 标签打在**系列**级；折射率、膜层、度数范围属于 SKU 属性，不进功能标签。
5. 分档（基础版 / 主推 / 标星）是**运营属性**，与功能标签分开维护，可按地区改。

## 1. 维度一：人群（决定用哪本手册）

| 标签 | 范围 | 说明 |
| --- | --- | --- |
| `青少儿` | ≤ 18 岁 | 核心是近视防控（青控）；3 个月复查 |
| `成人` | 19–44 岁 | 单光为主；视疲劳、功能型单光 |
| `中壮年` | ≥ 45 岁 | 老花、调节力下降；渐进 / 抗疲劳 / 看近方案 |

## 2. 维度二：解决什么问题 → 功能类别

| 功能类别（受控标签） | 顾客语言（说人话） | 典型验光单 / 主诉触发 | 会议里出现的系列（待核） |
| --- | --- | --- | --- |
| `普通单光` | 看清楚就行，基础款 | 单纯近视/散光，无特殊主诉 | 伊格尔 1.5（线下 399 套餐）、贝罗（线上 299，防蓝光） |
| `功能型单光-周边视野优化` | 边上看出去不变形、不晕 | 成人；高度数；对周边清晰有要求（设计师、开车） | SAP 锐界单光（双面自由曲面，5000+ 优化点）、豪雅新明锐 N3（单面自由曲面）、爱赞「背手」（转写，待核）、蔡司泽锐 |
| `视疲劳` | 看手机电脑到下午眼睛累、干、涩 | 主诉长时间近距离用眼；视功能检查提示调节问题 | 自营视疲劳系列（老品，素材优化被搁置）；1.56 S3（浙江视疲劳套餐） |
| `近视防控` | 让孩子度数长慢一点 | 青少儿；眼轴增长 | 星趣控 2.0（转写作「兴趣控/新曲控」）、多点离焦微结构、仿生复眼、双效（后两者 BI 未归类） |
| `渐进/看远看近` | 一副眼镜远近都能看 | 中壮年；老花 + 近视 | 中壮年手册内系列 待补 |
| `老花/看近` | 看手机小字看不清 | 中壮年 | 老花镜兑换活动、399/499 智能套餐（南区） |
| `变色` | 室内外一副搞定 | 户外多 | 变色片（南区 1000+ 功能型单镜片） |
| `太阳镜` | 户外防晒/开车 | 季节性 | 暴龙太阳镜活动 |
| `手机镜` | 看手机专用 | 转写作「小雅的手机镜」，待核 | 待核 |

## 3. 维度三：设计工艺（用来解释「为什么好」，不是卖点堆砌）

| 工艺标签 | 白话解释 | 备注 |
| --- | --- | --- |
| `自由曲面-单面` | 镜片一面按度数精细研磨 | 豪雅新明锐 N3 |
| `自由曲面-双面` | 前后两面都精细研磨，边缘更清晰、更薄 | SAP 锐界单光；厂商也叫「双面自由非球面」「自由双面曲面」 |
| `优化点数` | 研磨时计算的点数，本质是**研磨方式** | 锐界 5000+ 点；单独数字对顾客无意义，必须配对比画面 |
| `非球面` | 比球面薄、边缘变形小 | 待补 |
| `折射率` | 同度数下越高越薄（1.50 / 1.56 / 1.60 / 1.67 / 1.74） | SKU 属性，非功能标签 |
| `膜层` | 防蓝光 / 铂金膜 / 其他 | SKU 属性，非功能标签 |

> 领导要求：互动屏加一页「自由曲面研磨技术 / 优化点」专项，深挖工艺生产路径，比「子午线」那类讲法更能落地。

## 4. 维度四：运营分档（与功能标签解耦）

| 分档 | 含义 | 来源 |
| --- | --- | --- |
| `基础版` | 该功能类别里的入门款 | 功能型单光基础版：锐界单光、爱赞（同级） |
| `主推` / `标星` | 相同价位带里优先推的那一个 | 例：1400 价位带线下主推锐界（设计更好、定价合理、7 折） |
| `线上O2O` / `线下套餐` | 渠道属性 | 线上团单 vs 线下 POS 套餐，同价位要定主次 |

## 6. 验光单 → 标签 推荐规则（第一版思路）

```
IF 人群 = 青少儿                          → 近视防控（按原理 + 防控效果数据细分）
IF 人群 = 中壮年 AND 主诉看近困难            → 老花/看近 或 渐进（看远近需求）
IF 主诉 长时间手机/电脑 OR 视功能提示调节不足  → 视疲劳
IF 高度数 OR 主诉周边变形/开车/设计工作       → 功能型单光-周边视野优化
ELSE                                      → 普通单光
THEN 在命中类别内按 [分级, 主推标星, 毛利, 价位带] 排序，输出 2–3 个候选
```

- 规则里的阈值（"高度数" 多少度算高）待与验光师确认。
- 输出必须附「为什么适合你」：把触发规则的验光单项目用白话复述一遍。
