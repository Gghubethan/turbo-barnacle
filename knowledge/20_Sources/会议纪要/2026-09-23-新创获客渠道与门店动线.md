# 2026-09-23 新创获客渠道与门店动线（入职介绍）

**讲解**：发言人 2（部门负责人，镜框板块）、李亮（获客）。**对象**：三位新人。

## 部门介绍的三段式框架

1. 顾客到店**之前**：怎么获客。
2. 顾客**在店**：服务体验与流程。
3. 顾客**离店**：私域 / 老客运营。

## 获客渠道（李亮）

| 渠道 | 定位 | 备注 |
| --- | --- | --- |
| 大众点评 / 美团 | 有明确配镜意向、已在搜店，转化意向强 | 团单名称、主图、套餐展示要优化 |
| 抖音（视频 + 直播） | 流量最大、人群最广；本地生活强 | 冲动下单，客单高了会犹豫 |
| 小红书 | 种草、品牌信任、深度内容（专业服务） | 平台推优质内容 |
| AI 搜索（豆包 / DeepSeek） | 替代官网 / 搜索引擎 | 广告信息要能被 AI 引用 |
| 线下赛事 / 圈层 | 马拉松、越野跑、骑行、高尔夫 | 隐形（博士伦 / 强生）赞助合作；集团自有运动眼镜品牌与运动专区 |
| 门店线下活动 | 老客维护，高端 VIP 沙龙（穿搭 / 化妆老师） | 增加粘性、二次成交 |

- 线上偏拉新、门店偏老客，但不绝对：老客也会从点评团单再进店；顾客会多家对比。
- 老客资产是宝岛最珍贵的部分（多年高价值老客池），需要用户运营。

## 新人回答「先从哪个渠道入手」时的要点

- 提到了小红书 / 抖音 / 点评三个平台；负责人补充：不同平台价值与用户不同，要分清。

## 门店动线（发言人 2）

- 进店第一眼是镜框；专业和镜片无形，镜框、陈列、动线是实实在在能看到的差异。
- 镜框板块含：光学框、太阳镜、老花镜、智能眼镜。
- **每一步都提前设计**：不同人群进店只看到他想看的，且一路看到的东西越来越好、能提升单价。
- 进门第一桌 = 获客窗口（像橱窗），决定第一印象（时尚 / 专业 / 成熟）。
- 本店（写字楼白领店）两条主动线：
  - **先选框**的顾客：从 YSL / Gucci / 万宝龙 等时尚、品牌调性入口进，到潮牌区。
  - **先验光**的顾客：从验光室出来，先看到专业品牌（夏蒙、同理心高度数专用、One One 等）。
- 品牌详见 [[门店动线与A类陈列]]。
- 新人每两周轮岗：获客 / A 类 / B 类 / 老客；到 A 类板块时要把店内所有品牌与商品研究一遍。
