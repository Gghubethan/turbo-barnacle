# 2026-09-23 宝岛眼镜专业服务流程解析（门店实地讲解）

**讲解**：发言人 2（负责中壮年 / 渐进；后扩展到镜片、镜框、专业、获客、老客）、发言人 4（斌哥，青少儿 + 成人）。
**对象**：三位新人（含徐一轩）。

## 1. 验光前

- 自家 APP 验光程序：输手机号注册新会员 / 查老顾客历史资料。
- 验光室忙时由配镜师先做前期互动：了解需求、主诉（"最近眼睛有点累"）。

## 2. 视光中心「黑科技」四设备（验光室外）

| 设备 | 用途 |
| --- | --- |
| 眼轴测量 | 青少年必查；度数快速增长时眼轴也在加长 |
| AI 眼底 | 所有人可查；拍照出眼底情况，需专业解读 |
| 视功能快速筛查 | 坐上去约 90 秒出眼睛大概情况 |
| （第四台，转写缺失） | 待补 |

- 后方大屏同步显示检查画面，顾客坐着听讲解，不用凑过去看（体验设计）。

## 3. 验光室

- 综合验光仪等是任何眼镜店的基础。
- 最长验光服务约 **1 小时**：除度数外还查**视功能**。
- 套餐结构：**1+3 / 1+7 / 1+10** = 基础检查 + N 项视功能检查；从基础往上叠加，也可直接全项。
- 不同人群有不同检查建议与说明画面（资料会给到）。

## 4. 验光后：先讲解决方案，不是先挑框、更不是翻价目册

- 出验光室是为了腾出验光室；出来后在**互动屏**上逐项解读报告（视功能等），并给出建议方案。
- 讲「功能型单光镜片 vs 普通镜片」的区别：不变形 / 更清晰 / 同折射率更薄，配实拍对比图与供应商道具（蔡司两片对比板）。
- **画面里全程不出现价格**。价目册翻开第一眼就是价格 → 顾客心慌、死守预算、后面什么都不听。
- 讲完原理 → 点到具体品牌系列（如蔡司泽锐）→ 再看折射率（600 度建议 1.67 / 1.74）与膜层（防蓝光 / 铂金膜）→ 门店折扣 → 最后 A（镜框）+ B（镜片）合计。
- 顾客想先看框可以，但要在解决方案讲完之后；镜片与镜框有搭配约束（高度数镜片对框有要求）。
- 反例（以前的做法）：验出 300/400 度 → 问预算 → 翻价目册 → 塞防蓝光 → 600 元套餐成交 → 顾客戴了一年不知道自己买了什么。

## 5. 成交之后

- 取镜调整、告知售后权益 → **加企业微信**，不是为了发广告，而是做售后周期内的互动与**复查提醒**（成人半年到一年半；青少年 3 个月）。
- 老客运营的前提是「基于需求让顾客回店」，不是靠 3 折拉人；只喜欢折扣的顾客会被更低折扣吸走。
- 每类人群设计**生命周期**（小孩 / 成年 / 老年），配系统任务与回访要求 → 进店回店循环 → 拉新裂变。

## 6. MOC 部门做什么

- 找服务流程里顾客能感知「专业差异」的点，避免和快消 / 时尚品牌比价。
- 互动屏画面（折射率对比 4%/5%/8% 等）都是部门与专业、商品反复推敲后自己做的；供应商各画各的看不懂。
- 道具发门店时附使用说明；镜框陈列要跟着动线 / 主推 / 潮流经常调整（类比名创优品换货架）。
- 部门 = 后台各方（专业、商品、设计）汇聚到前台的「加工中心」。
- 新人每两周在获客 / A 类 / B 类 / 老客四个板块轮岗。

## 给新人的观察作业

- 路过眼镜店看门口放什么品牌、系列、台卡活动；打开微信看加了多少家企微、别家私域怎么运营；
  做专业的看看自己眼睛累不累。
