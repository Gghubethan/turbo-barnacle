# 2026-09-23 镜片分类与验光单解读培训（入职第 1 天）

**参与**：带教（发言人 1）、徐一轩。

## 交到手上的材料

- **三本人群手册**：青少儿（到 18 岁）、成人（到 44 岁；实际所有年龄段都可用）、中壮年（45 到七八十岁）。
  重点销售的商品都在里面。
- **两张门店验光单**（青少年 / 成年人）。

## 镜片分类（带教口述）

| 类别 | 解决的问题 |
| --- | --- |
| 普通镜片 | 基础 |
| 功能型单光 | 对周边视野有要求 |
| 视疲劳 | 长时间看手机 |
| 老花 / 调节力 | 年纪大之后看近、调节力下降 |
| 太阳镜 / 变色 | 户外 |

## 验光单要先弄懂的项目

- 视力检查；**主观验光 vs 客观验光**（区别是什么）；**视功能**（解决什么问题）；最终结果 / 处方。
- 逻辑：镜片最终解决的都是验光单里能呈现的问题 → 验光单要和具体商品关联起来，这就是 B 类主线。

## 两天内的任务

1. 优先了解现在在售的解决方案有哪些，每一类镜片解决什么问题。
2. 了解验光单每个项目干什么用（电脑到了之后查）。
3. 之后再想「解决方案卖给谁、怎么卖」。

- 徐一轩本人只有散光、不近视，也算「有问题」，可以拿自己当样本体验流程。
